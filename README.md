# لوح (Lawh)

سبورة رقمية بلا حدود لنظام Windows، بواجهة عربية كاملة. ارسم واكتب وأضف الأشكال والصور والروابط بين العناصر، واستخدم أدوات الرياضيات (خط الأعداد، المستوى الديكارتي، رسم الاقترانات)، ثم صدّر عملك إلى PNG أو SVG أو PDF.

## ⬇️ التنزيل

**[نزّل آخر إصدار من صفحة الإصدارات (Releases)](https://github.com/mikaneke/Lawh/releases/latest)** — اختر الملف `Lawh-<الإصدار>-x64.msi`.

### المتطلبات

- Windows 10 أو Windows 11 بإصدار 64 بت.
- لا يحتاج تثبيت أي شيء آخر (.NET مضمّن في المثبّت).

### التثبيت

1. شغّل ملف `.msi` الذي نزّلته ووافق على صلاحيات المسؤول.
2. يُثبَّت التطبيق في `C:\Program Files\Lawh` ويظهر في قائمة Start (واختصار سطح المكتب اختياري أثناء التثبيت).
3. ملفات `.lawh` تفتح في لوح بالنقر المزدوج.

> **تنبيه Windows SmartScreen:** المثبّت غير موقّع رقميًا حتى الآن، لذلك قد يظهر تحذير «Windows protected your PC». للمتابعة اضغط **More info** ثم **Run anyway**.

### الترقية وإلغاء التثبيت

- **الترقية:** شغّل مثبّت الإصدار الأحدث مباشرة؛ يستبدل النسخة القديمة تلقائيًا.
- **إلغاء التثبيت:** من «الإعدادات ← التطبيقات ← التطبيقات المثبّتة». يُزال البرنامج فقط، وتبقى مشاريعك وإعداداتك.

## الميزات

- لوح غير محدود: تحريك وتكبير حول المؤشر، شبكة، ملاءمة المحتوى، وألواح متعددة في المشروع الواحد.
- قلم وماركر شفاف، وممحاة جزئية أو للعنصر كاملًا.
- تحويل الرسم اليدوي إلى شكل منتظم بالضغط المستمر بعد الرسم.
- أشكال وخطوط وأسهم، وروابط ذكية تبقى متصلة بالعناصر عند تحريكها.
- نصوص عربية من اليمين لليسار، ونص مختلط عربي/إنجليزي.
- أدوات رياضيات: خط الأعداد، المستوى الديكارتي، رسم الاقترانات.
- تحديد وتحريك وتدوير وتجميع وقفل، ومحاذاة ذكية للشبكة والعناصر.
- صور باللصق أو السحب والإفلات (تُحفظ داخل المشروع).
- طبقات، وتراجع/إعادة.
- حفظ تلقائي واستعادة العمل بعد الإغلاق المفاجئ.
- تصدير PNG وSVG وPDF.
- شريط أدوات سريع، واختصارات لوحة مفاتيح قابلة للتخصيص، وملء الشاشة.

## أين تُحفظ بياناتك

| البيانات | المسار |
|---|---|
| المشاريع | حيث تحفظها أنت (ملفات `.lawh`) |
| الإعدادات والاختصارات | `%APPDATA%\Lawh` |
| نسخ الاستعادة التلقائية | `%LOCALAPPDATA%\Lawh\Recovery` |
